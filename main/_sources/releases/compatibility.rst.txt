Compatibility
#############

Each Hubble Device SDK release has been validated against the platform
versions listed below. Other versions may work but have not been tested
with that release. If you need support for a version that is not listed,
`contact us <mailto:support@hubble.com>`_.

.. warning::

   ``main`` is the development branch. Use a tagged release unless you
   need something that has not been released yet, such as support for a
   new chip or platform.
   The ``latest (main)`` row shows what the development branch
   is tested against today and can change at any time.
